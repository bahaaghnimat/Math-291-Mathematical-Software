# Math 291: Mathematical Software Packages
**Instructor:** Bahaa Ghneimat | **University:** Yarmouk University | **Initiative:** Zeta Team

## Overview
This repository contains the educational resources, computational scripts, and source codes for **Math 291 (Mathematical Software Packages)**. It serves as a comprehensive reference for university mathematics students learning symbolic computation and mathematical programming.

## Contents
* **Wolfram Mathematica (.nb):** Scripts covering calculus, advanced plotting, and algebra.
* **Maple (.mw):** Worksheets for solving differential equations, linear algebra, and numerical analysis.
* **Reference Booklet:** Digital materials and command summaries authored for peer instruction (managing cohorts of 100+ students per semester).

## About the Author
**Bahaa Ghneimat** is a mathematics senior at Yarmouk University and the Core Leader of **Zeta Team**. He specializes in applied computational mathematics, Python programming, and interactive mathematical education.
